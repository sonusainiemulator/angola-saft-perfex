# Contributing to Angola E-Invoice (SAF-T AO)

First off, thank you for considering contributing to this module! It's people like you that make the Perfex CRM community such a great place.

## How Can I Contribute?

### Reporting Bugs
- Use the **GitHub Issues** tab to report bugs.
- Before creating a new issue, please check if the bug has already been reported.
- Include steps to reproduce the bug and any relevant logs or screenshots.

### Suggesting Enhancements
- If you have an idea for a new feature or an improvement, open a **GitHub Issue** with the "enhancement" label.
- Provide a clear description of the proposed change and why it would be beneficial.

### Pull Requests
- Fork the repository.
- Create a new branch for your feature or bug fix (`git checkout -b feature/your-feature`).
- Commit your changes with clear messages.
- Push to your fork and submit a Pull Request.

## Coding Standards
- Follow the **Perfex CRM coding standards**.
- Ensure your code is well-documented.
- Use PSR-4 namespaces where applicable.
